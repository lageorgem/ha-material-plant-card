## [0.1.0] - 2026-10-12

Unreleased — first public release in preparation.

### Added

- Material 3 Expressive plant card for Olen's plant monitor integration. Full mode is the default, as in flower-card: a header and grouped metric tiles with a small tone-coloured icon and metric name in the title row, a history label on the right, a large current value with its unit and `Ideal a–b` below it. Only real problems selected by problem settings add a faint red gradient tint.
- Full-mode history exclusively from recorder hourly statistics; no raw history requests. Optional string `history_period`: `24h` (default), `3d`, `7d`, `14d` or `30d` (example: `history_period: 14d`). Measurement sensors require recorder statistics and `state_class: measurement`. Refreshes every 10 minutes.
- Optional string `full_display`: `summary` (default) or `graph` (example: `full_display: graph`). Summary shows ideal-bound ticks, a threshold-coloured min–max segment, current-value ring, average triangle and Min/Avg/Max badges. Graph shows a line coloured green inside the ideal band and error red outside, dashed ideal-bound guides, min/max triangles (red outside ideal bounds), and a latest-value ring, with no average marker or statistics row. Mouse hover or touch/drag shows the point's time and value; graph interaction does not open more-info, while the rest of the tile does.
- Graph minimum markers are upward triangles on the bottom edge; maximum markers are downward triangles on the top edge, each with a dot on the line at that point. Adaptive graphs zoom to the data when all values stay at or below the ideal minimum (dashed guide at the top), or at or above the ideal maximum (guide at the bottom); otherwise the full scale shows both ideal guides. Hover bubbles stay visible while hovered and Escape dismisses them; touching or hovering a graph does not highlight or activate its tile.
- Illuminance graphs with windows up to 3 days show sunrise/sunset as dotted vertical lines with sunrise/sunset icons, using Home Assistant's configured location. DLI day boundaries and graph time labels use Home Assistant's configured time zone. Refreshed `assets/graph-dark.png` shows below-minimum DLI in zoomed mode and illuminance sun lines.
- Optional `metrics` map keyed by measurement names, with optional per-metric `icon` (string, built-in default; example `mdi:thermometer-lines`), `problem_trigger` (string: `plant`, `out_of_range`, `low`, `high`, `never`; inherited from global problem settings; example `low`), `period` (string with the `history_period` choices, inherits it; example `7d`), `days` (number, rounded and clamped to 1–30, default 7; example 14), and `display` (string: `summary` or `graph`, inherits `full_display`; example `graph`). Explicit triggers override `problem_source`/`problem_sensors` and are independent of the monitor unless `plant`. Icon and trigger overrides apply in both modes; history and display settings apply in full mode.
- Cumulative sensors (`state_class: total` or `total_increasing`), including DLI, use maximum hourly recorded state per local day, representing DLI's daily total. `metrics.dli.days` selects 1–30 days (default 7) independently of `history_period`, including today's partial total. Label: `Today` for 1 day, otherwise `Daily max · N d`. Graphs show today's hourly values for 1 day (no min/max triangles), otherwise daily maxima; summary statistics describe daily maxima. Long-term statistics support 30-day windows when available. The large DLI value remains today's running total.
- Sun-based illuminance filtering with optional `metrics.illuminance.daylight_only` (boolean, default `true`; example `false`) and `daylight_offset` (number in minutes, rounded and clamped to 0–180, default 30; example 45). Uses Home Assistant latitude/longitude; only whole hourly buckets inside sunrise + offset to sunset − offset count. Label: `Daylight · 24 h` or the selected period. Excluded hours appear as graph gaps. A current reading outside the window is not counted or automatically forced red. Disabling filtering, or missing location coordinates, uses all hours and `Last …` labels. Compact mode is unchanged.
- Full-mode non-cumulative current values, rings and title icons turn error red outside ideal bounds even without selected problems, except for daylight-filtered illuminance outside its window. Eligible current values extend historical extrema without changing the hourly average. DLI current values retain the problem-setting colour; faint red gradient tints mark only selected problems.
- Optional boolean `hide_history` (default `false`; example `hide_history: true`) disables fetching and hides history labels and summary statistics. Summary retains ideal ticks and a current ring; graph retains empty ideal-bound guides. Current values and ideal ranges remain visible. Missing statistics show `—` in summary badges without a historical segment or average marker.
- Compact mode with circular three-zone range gauges, icons centred on the dial, active arcs and position dots. Coloured fill follows the track's thin low/high zones, thick just-right band and the same gaps.
- Success gauge colour in range (`--md-sys-color-success`, falling back to `--success-color`), neutral on-surface-variant out of range without a problem, and error colour for problems with bold, error-coloured value text. Logarithmic illuminance scaling for lux readings with positive minimum thresholds.
- Support for moisture, conductivity, temperature, illuminance, humidity, DLI, 24-hour DLI, CO₂, soil temperature and VPD measurements supplied by the integration.
- Cookie-shaped plant photos with configurable image override and a missing/broken-image placeholder; plant name, species or problem summary, and a red error circle with a centred **!** on the photo.
- Integration-driven problems by default (low illuminance at night can remain neutral), optional out-of-range gauge problems, and measurement filtering through `problem_sensors`.
- Optional bare iOS-style battery glyph with the level number inside; error colour below `battery_warn_level` (default 10%), otherwise neutral. `battery_ok_level` is accepted but ignored for flower-card compatibility and removed from the visual editor.
- Two-line Material plain gauge tooltips: `<Metric>[ · too low/high]` and `<value> <unit> · ideal <min>–<max> <unit>`. Touch long-press (about 0.45 s), mouse hover (0.5 s) and keyboard focus show the tooltip; Escape dismisses. Normal taps open sensor more-info; long-presses do not. Photo/name and battery taps open their respective more-info dialogs.
- Shared photo size and species header in both modes, configurable measurement order and visibility, and `hide_units` defaulting to `false` in both modes. When enabled, it hides only the unit beside full-mode values, but complete compact gauge value text. Tap tiles or gauges for sensor more-info.
- Compact width-measured, balanced gauge rows when gauges do not fit one row, with the extra on the first row and the last row centred (two-row examples: 5 → 3/2, 6 → 3/3, 7 → 4/3). Compact is approximately 327 × 160 px at 327 px width with six gauges, versus flower-card's 327 × 203 px; full-mode tiles are approximately 84 px tall and a six-metric full card is approximately 327 × 614 px.
- Home Assistant visual configuration form with Metrics, Per-metric settings, Problems and Appearance sections; one expandable per measurement in Per-metric settings.
- Material You theme tokens with Home Assistant theme fallbacks and reduced-motion support.
- Flower-card-compatible configuration keys, with `bars_per_row`, `show_care` and `extra_badges` accepted and ignored; independent implementation with no shared code.
- HACS/manual installation documentation, full-options and migration YAML examples, and content-addressed local deployment with SHA-256 verification before resource registration.
